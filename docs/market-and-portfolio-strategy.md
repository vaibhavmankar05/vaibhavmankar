# Portfolio Strategy — September 2026

## Market signals reviewed
- LinkedIn's India job index currently shows 10,000+ Power BI jobs and 16,000+ SQL Data Analyst jobs, with Pune among the listed locations. Counts are dynamic search-result snapshots, not a guarantee of unique vacancies.
- Current postings commonly combine Power BI with SQL, data modeling, DAX/Power Query, Python/PySpark and cloud/data-platform exposure.
- Recent India hiring research points to continued demand for data engineering, Python, SQL, React and AI/LLM capabilities. The portfolio therefore uses React as the product UI while keeping the professional identity centered on analytics and data.
- AI hiring is growing faster than overall IT hiring in recent 2026 reporting. This supports showing practical AI/RAG/automation work without repositioning the candidate as a pure ML engineer.

## Recruiter UX decisions
1. Show role and core stack above the fold.
2. Put proof of work before a long biography.
3. Give each project a business problem, technical approach and outcome/proof.
4. Keep professional-style work distinct from experimental/hackathon work.
5. Make resume, LinkedIn and email one click away.
6. Use job-market keywords naturally; do not keyword-stuff.
7. Keep the site fast, mobile-friendly and readable.
8. Avoid unsupported metrics or claims; only publish numbers that can be defended in an interview.

## Important gap to close
The current portfolio describes several projects well but has limited public evidence such as screenshots, GitHub repositories, demo links, before/after metrics and architecture diagrams. Adding these proof assets will improve recruiter confidence more than adding more technologies.
